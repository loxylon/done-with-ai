Что здесь совпадает со статьёй, а что упрощено?

Выполняются semantic labels, Rao–Blackwell targets, fixed-zero absorbing class, termination discount и Dual-CRL-PPO с GAE, value loss, entropy и annealed teacher CE. Критик — факторизация φ(s,a)·ψ(g) размерности 2. Политика и value — таблицы; вместо нейросетей, Adam и RAdam используется аналитический SGD. Это действующее обучение маленькой модели, а не воспроизведение бенчмарков статьи.

Здесь команда фиксирована на весь rollout. Награда 1 выдаётся на каждом посещении командуемого предиката, цели сами не завершают эпизод. Это упрощение относительно first-hit scheduler в notebook. Каждая итерация начинается со стартовой клетки. Опасность завершает эпизод; лимит шагов — truncation с value bootstrap. PPO не нормирует advantages. Все batch-градиенты — средние по шагам, повторные посещения суммируются.

Это журнал уже собранного rollout: на вкладке «Будущее» виден его остаток, но агент при выборе действия его не использует. Параметры сбора заморожены. Числа округлены только для показа; наведите на число или выгрузите JSON для полной точности JavaScript float64. Несколько маленьких обновлений не гарантируют решения задачи.
